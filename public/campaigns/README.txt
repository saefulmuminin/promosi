Banner campaign untuk halaman "Pilih Daun Kebaikanmu".

Taruh gambar banner di folder ini dengan nama file berikut (format .jpg):

  pendidikan.jpg   -> Pendidikan (Daun Hijau)
  ekonomi.jpg      -> Ekonomi (Daun Jingga)
  sosial.jpg       -> Sosial (Daun Kuning)
  dakwah.jpg       -> Dakwah (Daun Biru)
  kesehatan.jpg    -> Kesehatan (Daun Ungu)
  harapan.jpg      -> Harapan / Doa (Daun Merah)

- Rasio disarankan 16:9 (landscape). Gambar akan di-crop object-cover.
- Jika file belum ada, kartu otomatis menampilkan placeholder berwarna
  sesuai warna daun campaign tersebut.
- Untuk mengganti nama/format file, edit `banner:` di src/config/campaigns.ts.
